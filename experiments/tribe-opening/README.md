# 《万界文明》河谷流民开局实验 · 自主战棋 0.1

独立入口：`experiments/tribe-opening/index.html`。不修改正式 `game.html` 和世界权威数据。

## 目标
验证：简单确定性的棋子 AI 是否产生可供玩家预测、干预与长期构筑的战棋微循环。

## 运行
本实验已拆出 ES 模块，`file://` 双击不再可用，请在仓库根目录起一个 http 服务：

```
python -m http.server 8000
# 打开 http://localhost:8000/experiments/tribe-opening/
```

自动化验证：

```
node --test tests/tribe-opening.test.js
```

## 文件分工
| 文件 | 职责 |
|---|---|
| `tribe-sim.js` | 纯规则内核：地图、单位、BFS 寻路、指令生命周期、两种文明规则、日推进。无 DOM，可被 `node --test` 直接导入 |
| `app.js` | Canvas 绘制、按钮、点击选择与下令；只读内核状态，不持有权威 |
| `index.html` | 页面骨架与样式，加载上面两个模块 |

## 操作
- 点击我方“猎”“卫”选中，点击右侧“移动至此 / 指定攻击 / 坚守此地”，再点地图目标；“恢复自主”移除指令。
- 暂停/继续、1×/2×/4× 速度以及固定种子重开。
- 首次遇见捕食者时出现二选一行为构筑：“警戒本能”使猎团在 3 格内发现捕食者时撤离、威胁离开后自动恢复；“集群狩猎”让猎团主动与友方保持在 2 格内并额外造成 2 点伤害（日志会打印协同 +2）。
- 每 18 次模拟步进入新的一天，结算人口的食物消耗，并视情况补充野生单位。

## 2026-10-25 修复记录（本分支）
原版本是单文件内联脚本，本次只做缺陷修复与可测试化，未扩展美术，也未并入 `game.html`。

| 问题 | 根因 | 修复 |
|---|---|---|
| 棋子寻路卡死 | `stepToward` 只做贪心一步：仅当某个相邻格「更接近目标」才移动，遇到水面或其他单位就永久停在原地，指令也不收尾 | 改成六角网格 BFS 寻路（`findPath`），可绕开水面与占位；无路可走时明确放弃并记录日志 |
| 移动到被占用的格子永远到不了 | 目标格被单位占据时 `walkable` 为 false，距离永远不为 0，`order` 永远停在 `move` | 目标被占时改走「与目标相邻的可达格」，到位即收尾；加 `stall` 看门狗，连续 4 步无法推进就恢复自主并记日志 |
| 玩家干预看似无效 | 上一条的表现：下令后棋子原地不动，也不会回退自主，玩家无法判断命令是否生效 | 指令有明确生命周期：move 抵达/放弃、attack 目标消失或不可达、hold 抵达后驻守，全部写日志 |
| 集群狩猎构筑不生效 | 触发条件是「2 格内有友方」，但场上只有 1 支猎团、守卫又驻守营地不动，实战中几乎永不触发；且它只加伤害，猎团本身没有靠近友方的行为 | 集群狩猎下猎团会主动向最近友方合流（位移层面可观察），协同命中时打印「集群狩猎 +2」日志 |
| 构筑机会出现时猎团往往已经死了 | 猎团会主动扑 7 血 / 2 攻的狼，6 血换不过，默认对局里常在构筑前就被打散，装上规则也没有对象可作用 | 加生存判断：只有血量 ≤ 狼攻击 ×2 且狼仍然很硬时才脱离，不再自杀式扑击 |
| 警戒本能逃到营地后原地不动 | 撤离只是朝营地走，狼仍在 2 格内时既不还击也不离开 | 改成在 2 步可达范围内选「离威胁最远、其次离营地最近」的落脚点撤离，威胁离开 3 格后自动恢复自主，并记录「猎团本能撤离捕食者」 |

控制台：Chromium 实跑（加载、安装两种规则、移动/攻击/坚守/恢复自主、重开、1×→4× 速度、25 秒持续运行共 85 步）未出现 `error`、未捕获异常或 `console.warn`。原版本也未复现 JS 运行时异常——上表都是逻辑缺陷，不是抛错。

## 两种规则的实测差异（同种子 1117，浏览器内取样）
| 场景 | 无规则（基线） | 警戒本能 | 集群狩猎 |
|---|---|---|---|
| 猎团对距离 2 的狼，10 步后 | 狼 7→5，猎团 6→4 | 狼 7（未开火），猎团 6（未受伤） | — |
| 相邻友方时对鹿的一击 | 2 点（鹿剩 1 血） | — | 4 点（鹿当步死亡） |
| 同种子 12 步后 | 猎团常被打散 | 猎团满血，日志「本能撤离捕食者」 | 两只鹿被清空，日志「集群狩猎 +2」 |

`node --test tests/tribe-opening.test.js` 覆盖：确定性快照、BFS 绕水、占位目标收尾、攻击目标消失、警戒本能（双方都不掉血）、集群狩猎（加伤 + 主动靠拢）、200 步长跑无卡死。仓库全量 74 个测试通过。

## 重要边界
这是 **浏览器 Canvas 独立玩法实验**，不是成熟的 Three.js 微雕游戏、不具备存档、完整经济、其它文明、远征、卡牌生命周期、完整教学或正式流程。程序中的 AI、食物与战斗系临时规则。本分支只做了自动化测试与一次 Chromium 实机复验，**不等于真人玩法验收**。不要把“已推送 GitHub”误写为“已可玩验收”。

## 给开发者的下一步验证
1. 真人试玩：确认 3 分钟内能够遭遇狼、收到构筑机会，并能感到两种规则的差异；记录首次干预时间与无效操作。
2. 继续检查：野兽再生节奏、多单位挤在窄缝时的碰撞死锁、远程攻击掩体、时间尺度。
3. 集群狩猎目前依赖「友方在 2 格内」；若要扩展成多猎团协同，需要重新设计合流与目标选择，而不是简单提高加成。
4. 经过玩法验证后再将规则内核与正式六边形世界共享，**不要直接融合两套世界状态**。
