# 《万界文明》河谷流民开局实验 · 自主战棋 0.1

独立入口：`experiments/tribe-opening/index.html`。不修改正式 `game.html` 和世界权威数据。

## 目标
验证：简单确定性的棋子 AI 是否产生可供玩家预测、干预与长期构筑的战棋微循环。

## 操作
- 打开 `index.html`（原生 Canvas，无额外依赖），观察猎团、守卫、鹿与狼的自主行为。
- 点击我方“猎”“卫”选中，点击右侧“移动至此 / 指定攻击 / 坚守此地”，再点地图目标；“恢复自主”移除指令。
- 暂停/继续、1×/2×/4× 速度以及固定种子重开。
- 首次遇见捕食者时出现二选一行为构筑：“警戒本能”使猎团远离附近狼；“集群狩猎”让靠近其他友方战团的猎团额外造成伤害。
- 每 18 次模拟步进入新的一天，结算人口的食物消耗，并视情况补充野生单位。

## 当前已实现
六边形地块、森林/丘陵/河流显示、不可通过的水面、两支初始我方战团、鹿的逃跑、狼的攻击、选中与指令、简易 HP/食物/人口反馈、两种文明行为机制、确定性随机种子。

## 重要边界
这是 **浏览器 Canvas 单文件独立实验**，不是成熟的 Three.js 微雕游戏、不具备存档、完整经济、其它文明、远征、卡牌生命周期、完整教学或正式流程。程序中的 AI、食物与战斗系临时规则；没有运行浏览器实机验收。此分支尚未经过自动化测试。不要把“已推送 GitHub”误写为“已可玩验收”。

## 给开发者的下一步验证
1. 在 Chromium/Edge 真正运行，检查控制台，确认 3 分钟内能够遭遇狼、收到构筑机会，并看到差异。
2. 检查所有指定攻击 / 移动 / 坚守 / 恢复自主均有效；记录视频或截图。
3. 建立针对自主索敌、行为规则、指令优先级、饥饿与日推进的确定性测试。
4. 特别检查：初始猎团数量与集群狩猎触发、野兽再生节奏、单位碰撞死锁、远程攻击掩体、时间尺度。
5. 经过玩法验证后再将规则内核与正式六边形世界共享，**不要直接融合两套世界状态**。
