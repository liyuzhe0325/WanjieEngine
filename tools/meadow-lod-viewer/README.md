# 草地 LOD / 19 格拼接测试（独立工具）

> 状态：**实验性预览工具**，未接入正式游戏。页面代码已进入 GitHub；用于测试的 GLB **尚未上传到 GitHub**（当前连接无法直接从工作目录向 GitHub 传送大型二进制文件）。拉取后需要补齐五个资源才能正常查看。

## 文件位置

将以下模型放在 `tools/meadow-lod-viewer/assets/`：

| 文件 | 内容 |
|---|---|
| `base.glb` | 六边形原始石质底盘（测试暂用高模） |
| `lod85.glb` | 草地 LOD1，约 40,981 面 |
| `lod40.glb` | 草地 LOD2，约 9,249 面 |
| `lod22.glb` | 草地 LOD3，约 2,715 面 |
| `lod10.glb` | 草地 LOD4，约 730 面 |

这些资源已包含在对话中交付的 `Wanjie_Meadow_Viewer.zip` 中；如有该压缩包，只需把其中 `assets` 目录复制到本工具目录即可。**单纯 `git pull` 目前不能得到 GLB**。

## 启动

在 `tools/meadow-lod-viewer` 目录启动静态服务器：

```powershell
python -m http.server 8000
```

打开 http://localhost:8000 。页面依赖在线 CDN 的 Three.js。

## 功能

- 单块 / 19 格密铺
- 自动和手动 LOD 切换
- 草地高度偏移，定位和底盘穿插
- 六边形铺设间距，检查接缝
- 简易面数估计

## 局限与已知问题

- 只是外观检查页面，不是 GPU 性能/帧率基准，绘制调用尚未实例化
- 底盘仍为约 34 万三角面的高模
- 自动 LOD 采用距离阈值占位逻辑，尚非像素误差选择
- 两个模型的拼接尺度和水平边界仍未做精确重拓扑
- 草地当前材质随各 LOD 重复打包，尚未共享纹理
