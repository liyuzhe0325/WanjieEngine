# 《万界文明》开发流程：玩法主线 + 微雕资产并行储备

> 日期：2026-10-20。状态：[确认] 研发优先级和资产储备方向；具体开局内容、积分分配、接入批次为[候选]。本流程优先于旧文件中“当前优先接入平地美术”的排期，但**不撤销** ART_BIBLE 中已确认的微雕品质、完整六角实体与空间标准。

## 一、产品目标
《万界文明》是文明发展、卡牌构筑、世界改造与世界涌现的 3D 六角微雕战略游戏。现在不应把制作更多美术素材、调地形 LOD、完成模型接入当作游戏进展的替代品。先完成可进入、可选择、可行动、世界能变化且具有目标反馈的正式游戏体验；再持续扩充内容。

## 二、两条并行工作流
**A：玩法与内容（开发主线）。** 直接在 GitHub main 的现有六角世界基础上逐步建立正式游戏入口、游戏状态、交互、卡牌、组织和世界变化。数据驱动，先用清晰占位棋子与符号；优先交付可运行的玩家操作和可观察后果，不用一系列互不相通的 HTML 玩具代替正式游戏。核心卡牌维持已认可边界：简单单牌规则、真实目标/世界条件、永久挂载、过去构筑改变未来牌源；具体抽牌/经济未决。

**B：微雕模型资产库（并行支线）。** 用户 Meshy 有约 3000 积分且具有一个月使用窗口；额度是用户提供的当前预算，不推断单件价格或到期日。优先批量生成高复用基础件、风格锚点、玩家第一阶段需要的对象。制作原始高模、贴图、预览、出处/生成提示词和候选优化版并归档，允许暂不接入游戏；不要为了消耗积分盲目生成大量无用散件。标记“生成/待评审/通过风格/待适配/已接入”，不把生成成功写成游戏可用。

## 三、真实开发的固定循环
1. 从**可玩目标或已有 P0/P1 质量缺陷**选择一个小范围任务；确认不违反设计宪章。
2. 先用现有六角世界与占位图形实现行为：玩家输入 → 规则验证 → 世界结算 → 界面反馈。代码写在明确的正式游戏模块，避免新建独立正式路线。
3. 在同一入口执行测试和真实浏览器操作；按 GAME_QUALITY_001 记录 CODE_ONLY/TESTED/PLAYED/ACCEPTED、运行证据、问题和复验。
4. 由已经稳定的游戏实体与空间约束反向建立资产需求；美术资产生产可并行，但**默认不阻塞本轮玩法**。
5. 只有当模型用途、占格、规格及资产质量均基本合格，而且本轮接入不会妨碍核心体验时，才安排 GLB/LOD/材质集成。
6. 更新开发记录，下一轮优先解决重要体验和质量问题，而不是堆新功能。

已有 WQ-001/002 代码修复**未完成实机验收**；WQ-004 实机画面/FPS 缺口应保留。新流程允许将大规模艺术集成延后，**不允许把现有 P1 数据损坏、启动失败或重大交互缺陷假定解决**。

## 四、资产批次与登记
建议先批次储备（候选，非完整内容定稿）：
- 标准：六角草地/荒地、可复用植物岩石、原始建筑/营地、基本单位；
- 扩展：同族地形变体、资源点、早期势力形象；
- 暂缓：尚未确定玩法的巨大奇观、低复用英雄或大型特殊建筑。

每份资产保留：稳定 ID、中文名、对应游戏对象 ID（可空）、来源/许可/生成提示、原始 GLB 和贴图路径、是否是高模母版、三角面/贴图规格、预览图、六角尺寸与坐标适配状态、风格审核结果、接入状态。当前可在本地资产目录登记；不要将私人付费原件或超大二进制未经确认直接上传 GitHub。文件夹建议 `Assets_Library/Style_Anchors`、`Terrain`、`Units`、`Buildings`、`WorldObjects`；资产库是独立存储方案候选，**不是当前仓库已存在的目录**。

## 五、单人/AI 开发协作与验收
- **唯一长期主线 main**；严禁把早期根目录方格编辑器 `src/world.js` 与六角世界 `src/hex-world.js` 当作同一权威世界。
- 设计、已提交代码、浏览器已运行、已验收四种事实分开记录。
- 每轮报告说明：完成什么、依据什么验证、哪些不合格、修了什么、下一轮做什么。
- 先保持已有入口不被破坏，再逐模块整合；不要直接全量合并历史分支。
- 遇到缺模型时允许清楚标识的占位物；不得把占位效果宣布成微雕美术达标。
- 美术质量宪章长期保留；**当前排期是玩法优先，美术模型生产并行，正式接入延迟**。

## 六、最近的可执行工作顺序
**近期 1：** 确保当前六角实验的存档和模型缺失提示可运行、可复验；这属于保护现有成果，不代表继续扩大美术研究。

**近期 2：** 在权威六角世界上建立正式游戏入口和最初的玩家操作链（选格、看对象、提交合法行动、观察世界变化），占位显示即可；优先解决方格与六角游戏状态分裂。

**近期 3：** 用少量真实内容实现文明和卡牌最初的持续玩法；不能把演示牌当成正式卡池。随后再扩展世界反馈、单位、组织、本土势力。

**并行：** 在 Meshy 有效期内按基础资产包制作并保存微雕母版，先审核和归档，暂不强行接入。
