# 卡牌 × 世界规则：第一个可复现实验

范围：`src/card-world-experiment.js` 与 `tests/card-world-experiment.test.js`，与地图组现有 `world.js`、主入口、渲染完全隔离。

**设计问题：** 同一张牌不选择“森林模式/敌人模式”，只对目标施加世界干预：`spark` 增加热量 55；`rain` 增加湿度 45。每次调用 `stepSimulation`，统一检查燃料、湿度、热量、邻居燃烧状态，由世界规则决定点燃、蔓延或熄灭。

**不是定稿：** 数值阈值和结算步长均为测试常量；不是完整火灾物理、文明时钟、卡牌成本、抽取/来源/概率波，也没有把 `world.js` 地形直接映射为燃料/湿度。刻意不改主游戏，以免抢地图组定义权。

运行 `npm test` 或 `node --test tests/card-world-experiment.test.js`。验收先看：同牌跨环境、邻接蔓延、下雨熄火、顺序无关、非法动作不修改状态。下一步再讨论适配现有世界数据的只读投影与事件回写边界。
