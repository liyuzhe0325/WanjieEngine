# 世界状态写入基准（诊断工具）

运行 `node benchmarks/world-write.mjs 1000`，输出五轮计时的中位数，第一轮预热不计。比较当前 `setCell` 直接修改和 `createWorldStore().patchCell` 的完整复制写入开销。

当前世界固定为 24×24（576 格），这只衡量既有方格世界的基线成本。**不是**未来六角文明模拟、大地图吞吐量或渲染性能的保证。

此工具不设置“通过”的性能阈值，因为结果依赖 CPU、Node 版本和环境。解释数据时还需考虑两组操作的语义并不完全相同：直接修改缺少状态隔离；Store 每次复制、验证、提交整张地图。后续若要引入局部变更，需要建立独立的正确性测试和等语义基准，再替换实现。
